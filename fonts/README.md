# 默陌字体

把你有使用权的默陌字体放在这里，命名为 `momo.ttf` 或 `momo.otf`，然后重启 KakaPin。

本项目不分发第三方字体文件，也不会自动下载字体。默认使用字体内部的 `momozhuanji` 字体名称；请选择与原项目相同的默陌专辑字体。若字体位于其他目录，可在 `kakapin.config.json` 的 `font` 字段指定文件路径，或设置 `KAKAPIN_FONT`。

找不到字体时，启动器会提示；没有小字的影片仍可导出。有小字时导出会明确提示缺少字体，避免悄悄换成另一种字体。浏览器预览可能使用系统后备字体，以启动器检查结果为准。

原 Mac 上已安装的 `~/Library/Fonts/1610522684528356.ttf` 会自动识别，不再依赖特定用户名。
