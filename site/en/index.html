Your next album film

Bring your photos.
Start locally.

Install Node.js 22+ and FFmpeg / ffprobe. Download and extract the source, then run in its folder:

npm ci
npm run launch

Next time, double-click “启动 KakaPin.command” on Mac or “启动 KakaPin.bat” on Windows. Standalone App / EXE installers are not available yet.

A few things to know

  • Composition is 1920 × 1080 landscape. Other ratios fit with padding.
  • Source video audio is not exported. Separate music is supported; automatic beat detection is not.
  • Captions require your own licensed Momo font. Caption-free films need no font.
  • Real exports have been tested on macOS. Windows launch support is implemented, but full on-device acceptance is pending.
  • The application UI is currently Chinese; this website and the README have English versions.
