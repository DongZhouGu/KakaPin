从素材到影片

你来决定故事，
其余交给工作台。

01

把喜欢的放进来

导入照片和视频，按横竖比例自动组合画面。视频按完整时长播放，不跟随照片的停留秒数。

02

给回忆一点氛围

选模板、改底色、写小字。全片统一设置，也可以为某一个画面单独调整排版、停留和转场。

03

按自己的节奏成片

拖动故事板排序，混用不同转场。音乐与文字都可选，最后在自己的电脑上渲染 MP4。

02 / 项目库

上次的回忆，不用从头再来。

用封面找回项目，继续编辑。修改自动保存在本机。

03 / 素材管理

不放这一张，也不用删除原片。

「移出影片」后不参与预览和导出；可以撤销，或重新加入影片末尾。

04 / 本机导出

选好画幅，交给电脑渲染。

常见比例、自定义尺寸、标准或精细画质。当前 4K 为 1080p 合成后放大，非原生 4K 细节。

安心留在本机

照片不用上云，
回忆不加水印。

无账号，无素材云上传。导入与移出不改写源文件，照片、项目和导出保存在你的电脑上。这个官网只做介绍，不是在线编辑器。

开始你的下一部影片

准备好照片，
从本机开始。

安装 Node.js 22+ 和 FFmpeg / ffprobe，下载源码后运行：

npm ci
npm run launch

以后可双击「启动 KakaPin.command」或「启动 KakaPin.bat」。目前没有独立 App / EXE 安装包。

下载源码 ZIP ↓完整启动指南 ↗

开始前，了解这些

  • 当前以 1920 × 1080 横版构图合成；其他比例等比适配并留边。
  • 视频原声暂不导出，可另外添加背景音乐；尚无自动音乐卡点。
  • 小字需自行提供有使用权的默陌字体；无文字影片不需要字体。
  • macOS 已验证真实导出；Windows 已适配启动，但尚未完成实机端到端验收。
