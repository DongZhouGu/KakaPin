# KakaPin · 使用指南

选好照片，轻松拼成片。KakaPin 是与 KakaPick 同系列的本地相册视频编辑器：导入照片和视频，按横竖比例自动组合画面，在浏览器中调整相纸、文字与转场，最后由 FFmpeg 导出 MP4。

界面延续 KakaPick 的深灰画布、品牌橙、双取景框标志和系统无衬线字体。KakaPin 使用播放符号区分成片功能；详细约定见 [品牌规范](brand.md)。品牌仅作用于应用界面，不给用户画面添加水印或改变模板调色。KakaPick 与 KakaPin 目前独立运行，不包含自动项目同步。

## 启动

日常使用可直接双击 **`启动 KakaPin.command`（Mac）** 或 **`启动 KakaPin.bat`（Windows）**，自动检查环境、启动服务并打开浏览器。重复启动会复用同一服务。完整的首次安装、迁移和故障说明见 [双击启动说明](../双击启动说明.md)。

需要 Node.js 22+ LTS、FFmpeg、ffprobe。默陌字体优先读取 `fonts/momo.ttf` / `fonts/momo.otf`，也支持配置文件和原 Mac 的已安装字体。缺少字体时仍可导出无文字影片。

```bash
npm ci
npm run launch
```

打开 http://127.0.0.1:4177 。服务只监听本机。开发时可用 `npm run dev`。

## 编辑流程

1. 首页是项目中心：查看真实画面封面、风格、画幅、时长与修改时间；支持搜索、排序、重命名。点“新建影片”导入照片和视频、选择风格。
2. 左侧管理素材、预览模板或添加分行文字；点击素材定位对应画面。每张素材卡片下方常驻“移出影片”：照片或视频不再参与预览和导出，但文件与已保存的小字保留在“已移出”中。点“多选”可批量操作，“全选结果”只选择当前搜索／类型筛选的结果。“重新加入”将素材作为独立画面追加到末尾；顶部“撤销”则恢复原来的分组、排版与位置。移出全部素材需确认；没有画面时禁用播放与导出。
3. 中央预览支持播放、拖动进度和全屏。视频按原时长播放，不添加旋转或抖动。网格画廊支持可关闭的逐张展开动效，其余照片停留画面保持静止。
4. 右侧“当前画面”设置单页排版、停留、小字和进入转场。“全片设置”统一提供画幅、风格、默认排版、照片停留、字幕开关、片头和转场权重。
5. 默认排版可分别设置单图、双图和视频页面，先查看影响数量再应用；保留原素材分组、顺序、停留、文字和转场，并默认保护手动版式。未应用的排版有“待应用”提示，可恢复到已保存值。
6. 底部故事板可拖动排序或前移／后移。全片设置中的“重新组合照片”支持自动组合、每张一页、每两张一页、每四张一页，显示页数与预计时长并确认后执行。默认保护手动调整的页面，视频始终单独完整播放；重组可以撤销。
7. 编辑自动保存；撤销／重做适用于当前打开期间的文字、样式、排版、顺序等调整。同一页面内返回项目库再打开未被其他窗口修改的项目，会保留撤销记录；追加素材、修改音乐或刷新页面会重置该记录，原素材保留。
8. “项目库”返回首页；“继续编辑”恢复该浏览器上次选中的画面、播放位置和设置面板。“上次打开”按实际访问记录，不按修改时间选择项目。记忆保存在浏览器本地，清除站点数据后会重置。
9. 导出前先完成保存。保存失败会阻止导出；版本冲突可以从顶部保存状态处理。导出进度可收起，任务继续运行。

## 模板与背景

- 共 16 种风格、19 款模板；在预览页左侧「模板」中按珍藏系列／简约／胶片／相纸／婚礼筛选，使用当前画面比较效果。首页也可预选风格。
- 珍藏系列：暗房印样、手工剪贴、杂志跨页、实体影集、网格画廊、水墨显影。六款使用不同的材质与布局，按素材原比例放置；四张竖图自动四列排列。展开「模板用法与动效」可应用推荐转场、调整分组、关闭画廊聚焦；不会静默覆盖手动转场。详见 [设计简报与参考](collection-brief.md)。
- 纯黑影院：纯黑背景、原色无框，不叠加胶片滤镜、颗粒或暗角。适合视频与干净的照片展示。
- 拍立得日记：宽底白色相纸，小字放在下方相纸内。
- 全片设置中的“画面背景色”可选黑色、白色等预设，也可用选色器或输入 HEX 色号。拍立得只改变外部底色，保留白色相纸和照片调色；选“模板默认”恢复原本底色。自定义颜色随项目保存，切换模板时保留，支持撤销。照片、视频、片头、故事板和项目封面同步使用此颜色；非横版输出的留白区域也使用自定义底色。胶片模板仍保留固定的相纸边缘与颗粒效果。
- 留白画报：杂志式留白、原色影像，小字与照片分离。
- 黑白纪事：灰阶调色、银色细边与深色背景。
- 暖棕相纸：复古棕调、旧纸质感和双层细线。
- 森系婚礼：鼠尾草绿色相纸、植物线描。
- 樱粉誓言：柔粉花瓣、圆角白色相纸。
- 复古胶片：经典彩负、哑光黑边、银盐片框，以及无框电影；均无穿孔。
- 法式留白：奶油纸色和柔和低饱和画面。
- 典礼序章：暖调相纸，可选标题片头。
- 分行文字每行对应一项素材，支持空行、逐项修改、隐藏和全部清空。使用默陌手写字体，无强制字幕。
- 背景音乐可选，可添加、更换或移除。视频原声目前不参与导出。

模板不增加固定文案，不旋转照片，不加入持续抖动。切换可以撤销，不会覆盖单页排版、时长和转场。新模板的构图、相纸图形、笔刷遮罩和动效公式由预览与导出共用。纸页翻动为 2D 曲边与折面效果，不是 3D 书籍物理模拟。转场共 9 种，均可按相对权重混用。

预览区外侧使用中性灰衬底，画幅边缘有细线提示；两者仅用于编辑时区分边界，不会出现在导出影片中。影片本身的背景由所选风格决定。

## 输出与已知边界

支持 16:9、9:16、1:1、4:5、自定义偶数尺寸（320–7680 px）及横／竖版 4K 输出，H.264、30 FPS。

当前渲染器仍以 **1920×1080 横版构图**合成：其他画幅等比适配、空余区域使用自定义底色（未设置时填黑）；4K 是放大输出，不是原生 4K 构图。界面会明确提示这一点。浏览器预览使用轻量资源，调色、文字边缘及转场以最终导出为准。

一次可导入最多 1000 项素材，单个文件上限 8GB。素材、项目与导出保存在 `.runtime/`，原始源文件不会改写。项目保存为原子文件替换；并发修改串行处理并检查版本。测试可通过 `PORT` 和 `ALBUM_RUNTIME_DIR` 指定独立端口与目录，不必触碰真实项目。

## 检查

```bash
npm run check
npm test
npm run doctor
```

模板实导出回归：先用独立的临时目录启动测试服务，避免改动真实项目。

```bash
PORT=4182 ALBUM_RUNTIME_DIR=/tmp/wedding-style-test node server.mjs
# 在另一个终端运行，传入两张本地测试照片：
node scripts/test-style-exports.mjs /tmp/wedding-style-test photo-a.jpg photo-b.jpg
```

测试脚本在临时环境中逐一导出所有模板，验证文件尺寸、时间线长度、视频完整时长，并生成新风格的对照图。

自定义背景色实导出回归使用同一独立服务：`node scripts/test-background-exports.mjs /tmp/your-qa-runtime photo.jpg short-video.mp4`。覆盖模板默认、纯黑、自定义蓝色、白色相纸不变、照片色彩不变、完整视频时长和非横版留白颜色。

素材移出实导出回归：`node scripts/test-media-exclusion.mjs /tmp/your-qa-runtime photo.jpg short-video.mp4`。覆盖片头／成片只使用参与素材、视频完整时长、空影片导出保护、撤销与重新加入持久化、保存校验，以及移出后追加同名文件不覆盖原素材／缩略图／预览。

单元测试覆盖全片／单页设置隔离、默认排版与重组保护、素材顺序、撤销恢复、项目摘要与浏览位置记忆、文字引用、文档校验、完整视频时长、转场时间线和短片转场边界。另已进行浏览器手动回归：项目搜索排序、重命名、打开返回、恢复位置、批量排版、重组确认与撤销、编辑保存、模板选择、追加素材、视频完整预览和实际 MP4 导出。完整测试方法见 [测试说明](testing.md)。

本次界面参考 OpenCut / OpenReel 等编辑器的资源区、预览区、属性区与时间线分工，使用原生 HTML/CSS/JavaScript 实现，没有引入它们的代码或额外编辑器框架。
