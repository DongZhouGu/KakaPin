# KakaPin v1.0.0-beta.1 · 本地相册成片预览版

## 中文

首个可下载的源码启动包。**这是「本机服务 + 浏览器」版本，不是免环境的 App / EXE 安装包。** 同一个 ZIP 可用于 macOS 与 Windows，依赖需在目标系统首次安装。

### 下载哪个文件

- `KakaPin-v1.0.0-beta.1-macOS-Windows.zip`：推荐下载，含程序源码、Mac / Windows 双击启动器、使用说明和配置示例。
- `SHA256SUMS.txt`：ZIP 的 SHA-256 校验值。
- GitHub 自动附带的 `Source code (zip / tar.gz)` 是代码快照，不是另一套安装器。

### 解压后怎么用

1. 将 ZIP **完整解压**到自己的文件夹，不要在压缩包内直接运行。
2. 安装 **Node.js 22+** 和包含 `libx264` / `xfade` 的 **FFmpeg + ffprobe**。工具放进 `bin/` 或加入 PATH。
3. Mac 双击 `启动 KakaPin.command`；Windows 双击 `启动 KakaPin.bat`。首次提示时输入 `y` 安装 Node 依赖，需要联网。
4. 检查通过后浏览器打开 `http://127.0.0.1:4177/`。使用期间保留启动窗口，结束时按 `Ctrl+C`。

也可在解压目录执行 `npm ci`、`npm run launch`。Mac 若提示无执行权限，在解压目录运行 `chmod +x "启动 KakaPin.command"`；不需要关闭系统安全功能。

### 这版能做什么

- 照片与视频混排，按横竖比例组合画面，视频完整播放。
- 19 款模板、自定义背景色、全片与单页排版、9 种转场及占比设置。
- 素材移出与恢复、故事板排序、可选小字和音乐、本机 MP4 导出。
- 同品牌的中英文官网与真实产品截图。

### 包含与排除

包内包含已入库的产品代码、文档、官网和经过授权的无正脸界面截图。**不包含 `marketing/` 小红书图文、`videos/` 宣传视频工程、私人照片原片、项目数据、渲染结果、`node_modules`、本机配置、字体、Node.js 或 FFmpeg 二进制。** 本地宣发文案不提交到 GitHub，也不参与打包。

### 已知限制

- 当前按 1920 × 1080 横版构图；其他比例等比留边，4K 为放大输出。
- 视频原声暂不导出，可另加背景音乐；没有自动音乐卡点。
- 画面小字需自行提供有使用权的默陌字体；无文字影片不要求字体。
- macOS 已做真实导出验证；Windows 启动及路径已适配，CI 不等于完整 Windows 实机验收。
- 预览版，升级前先备份旧目录及 `.runtime/`，不要直接覆盖唯一一份相册数据。跨系统不要复制 `node_modules`。

源码公开，但尚未选择开源许可证；展示照片保留其各自权利。

## English

The first downloadable source-and-launcher preview. **This is a local server + browser application, not a standalone App / EXE installer.** The same ZIP works as source for macOS and Windows; install dependencies on the destination system.

### Download and start

1. Download `KakaPin-v1.0.0-beta.1-macOS-Windows.zip` and extract the entire folder. `SHA256SUMS.txt` provides its SHA-256 checksum.
2. Install **Node.js 22+** and **FFmpeg / ffprobe** with `libx264` and `xfade`. Add the tools to PATH or the app’s `bin/` folder.
3. Double-click `启动 KakaPin.command` on Mac or `启动 KakaPin.bat` on Windows. Approve the initial dependency installation with `y`; it needs internet access.
4. The browser opens `http://127.0.0.1:4177/`. Keep the terminal open while using the app; press `Ctrl+C` to stop.

Alternatively, run `npm ci` and `npm run launch` in the extracted folder. GitHub’s automatic source archives are code snapshots, not additional installers.

### Included

Photo/video mixing, full-duration videos, 19 looks, custom backgrounds, whole-film and per-scene settings, nine transitions with weights, reversible media exclusion, optional captions/music, and local MP4 export. Chinese and English product documentation are included; the application UI is Chinese.

### Excluded

No `marketing/` campaign drafts or Xiaohongshu content, `videos/` promo projects, original personal photos, runtime albums, rendered exports, local config, `node_modules`, fonts, Node.js, or FFmpeg binaries. Authorized interface screenshots without front-facing portraits are included. Campaign copy stays local and is never committed or packaged.

### Preview limitations

- Fixed 1920 × 1080 landscape composition; other ratios fit with padding. 4K is upscaled, not native 4K detail.
- Source video audio is not exported. Separate music is supported; automatic beat detection is not.
- Captions require your own licensed Momo font. Caption-free exports do not.
- Real exports are tested on macOS. Windows launch support and CI checks do not constitute full on-device acceptance.
- Back up your existing folder and `.runtime/` before upgrading. Do not copy `node_modules` between operating systems.
