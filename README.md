## 把回忆，连成一部影片

你决定放哪些照片、说什么话、用怎样的节奏。KakaPin 负责组合画面和渲染，不替你做最终的审美判断，也不向成片添加品牌水印。

适合婚礼、旅行、家庭记录和摄影作品集。[KakaPick](https://github.com/DongZhouGu/KakaPick) 帮你选片，KakaPin 帮你成片：共用品牌语言，目前独立运行，没有项目自动同步。

## 从素材到影片

1. **导入照片和视频。** 自动读取尺寸与视频时长，生成轻量预览，保留导入的原始素材。
2. **选一种氛围。** 在预览中比较 19 款模板，选择胶片、相纸、剪贴、画廊或干净的黑底。
3. **整理画面。** 自动组合或手动调整排版，拖动故事板排序；不想使用的素材可以移出并恢复。
4. **写自己的小字。** 按行填写文字，逐张修改，也可以全部清空；照片停留、转场类型和混用比例由你决定。
5. **在本机导出。** 保存后导出 H.264 MP4。视频使用完整时长，不受照片停留秒数限制。

## 核心能力

- **本地处理：** 无账号、无云上传；素材、项目和导出保存在自己的电脑上。
- **照片与视频混排：** 根据比例组合单图、双图和图组，视频独立完整播放，不人为添加照片旋转或持续抖动。
- **全片与单页分开设置：** 风格、背景色、默认排版和转场可统一设置，手动调整的页面默认受到保护。
- **16 种风格、19 款模板：** 支持预览切换、自定义背景色、可关闭的画廊聚焦动效和 9 种转场。
- **可恢复的编辑：** 自动保存、当前会话撤销／重做、素材移出与重新加入、项目搜索和继续编辑。
- **可选文字与音乐：** 分行小字使用自行提供的授权默陌字体；背景音乐可以添加、更换或移除。

## 模板风格

| 系列 | 可选模板 |
| --- | --- |
| 珍藏系列 | 暗房印样、手工剪贴、杂志跨页、实体影集、网格画廊、水墨显影 |
| 胶片 | 经典彩负、哑光黑边、银盐片框、无框电影、黑白纪事 |
| 相纸 | 拍立得日记、留白画报、暖棕相纸、法式留白 |

胶片模板没有上下穿孔。背景支持预设颜色、选色器和 HEX；拍立得的外部底色可改为黑色，白色相纸保留。模板选择不会静默重排素材或覆盖单页转场。详见[模板与画面设置](docs/user-guide.md#模板与背景)。

## 快速开始

### 首次准备

1. 安装 [Node.js](https://nodejs.org/en/download) 22 或更新的 LTS（本机已验证 Node.js 24）。
2. 准备 [FFmpeg 和 ffprobe](https://ffmpeg.org/download.html)，需要 `libx264` 编码器与 `xfade` 滤镜。将可执行文件加入 PATH，或放进项目的 [`bin/`](bin/README.md)。
3. 下载仓库源码并解压，或运行下面的命令。当前没有独立的 `.app`、`.exe`、DMG 或安装包。

```bash
git clone https://github.com/DongZhouGu/KakaPin.git
cd KakaPin
npm ci
npm run launch
```

启动器检查环境后打开 `http://127.0.0.1:4177/`。只监听本机；使用期间保留终端窗口，结束时按 `Ctrl+C`。首次安装依赖需要网络，日常本地编辑与渲染不需要 Codex。

### 以后双击打开

| 系统 | 启动文件 |
| --- | --- |
| macOS | `启动 KakaPin.command` |
| Windows | `启动 KakaPin.bat` |

双击启动器也能在征得同意后安装缺少的项目依赖，但不会替你安装 Node.js、FFmpeg 或字体。重复启动会识别同一服务，不会强制关闭占用端口的其他程序。

如果需要画面小字，将有使用权的**默陌专辑字体**放入 `fonts/momo.ttf` 或 `fonts/momo.otf`；字体不随仓库分发。没有字体仍可导出无文字影片。遇到启动问题先运行 `npm run doctor`。

完整步骤、配置路径、Windows 安装注意事项与旧项目迁移见[双击启动说明](双击启动说明.md)。不要跨系统复制 `node_modules`；在目标系统重新运行 `npm ci`。

## 输出与当前限制

- 输出 H.264、30 FPS，提供 16:9、9:16、1:1、4:5、横／竖版 4K，以及 320–7680 px 范围内的自定义偶数尺寸。
- **内部仍以 1920×1080 横版构图合成。** 其他画幅等比适配并留边；4K 是放大输出，不是原生 4K 构图。
- **视频原声目前不参与导出。** 可以另外添加背景音乐；没有自动音乐卡点功能。
- 照片预览使用轻量资源。浏览器与 FFmpeg 的文字边缘、调色和转场可能有差异，以成片为准。
- 一次最多导入 1000 项素材，单个文件上限 8 GB。HEIC 与部分视频格式取决于本机解码器，不是 RAW 显影工具。
- 已在 macOS 做过启动与真实 MP4 导出验证。Windows 启动和路径处理已适配，但尚未完成真实 Windows 机器上的端到端验收。
- 没有云同步、多人协作、安装包自动更新或任意比例的独立构图系统。纸页翻动为 2D 效果，不是 3D 书籍模拟。

## 数据与安全

默认数据目录为项目下的 `.runtime/`，包含素材副本、预览、项目状态和导出文件。源文件不会因导入或移出影片而被改写。备份或跨电脑迁移时，停止服务后复制整个运行目录。

Git 仓库只收录程序与文档，排除 `.runtime/`、`.backups/`、本机配置、字体、视频工具与私人素材。**Git 不是相册数据备份。** 若自定义运行目录，请把它放在仓库外或自行加入忽略规则。

服务面向可信的单用户本机环境，不应通过端口转发、反向代理或公网部署对外提供访问。它没有 KakaPick 的全部安全加固能力；具体边界与漏洞报告方法见 [SECURITY.md](SECURITY.md)。

## 开发与贡献

原生 HTML / CSS / JavaScript 前端，Node.js / Express 服务，Sharp 处理图片，FFmpeg 负责视频编码。无需前端构建步骤。

```bash
npm ci
npm run dev
npm run check
npm test
```

语法检查与单元测试不需要私人照片、FFmpeg 或字体；实际导出测试另有环境要求。CI 在 macOS、Windows、Linux 上检查 Node.js 22 / 24，不能替代各系统的导出和交互验收。

请先阅读[贡献指南](CONTRIBUTING.md)、[架构说明](docs/architecture.md)和[测试说明](docs/testing.md)。发布记录见 [CHANGELOG.md](CHANGELOG.md)，完整文档索引见 [docs/README.md](docs/README.md)。
